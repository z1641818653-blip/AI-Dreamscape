AI 聊天室教程

从三人辩论到大型讨论赛：角色、目标、轮次与用户介入指南

目录

这不是普通群聊

AI 聊天室是一张可以编排角色、立场、顺序和讨论目标的“多人思维桌”。你可以旁观 AI 自主讨论、随时插话，或者把自己加入固定发言顺序。

第一次使用：在左侧加载“展示模板”。它包含三名角色、完整目标和 16 条示例记录，是理解页面最快的入口。

一分钟开局

  1. 添加至少两个 AI，填写名称和角色 Prompt。
  2. 设置讨论目标，并选择自由讨论、方案共创或正反辩论。
  3. 新手建议先选择“固定 2～3 轮”。
  4. 点击“开始自动讨论”，或发送第一条问题触发讨论。

角色设置

项目作用建议
添加 AI创建一个可配置模型、Prompt 和温度的角色。每个角色应有不可替代的任务。
添加用户把你加入固定发言顺序，只需要名字。偶尔插话不必添加，使用“插入发言”即可。
名称聊天显示名，也是其他角色点名回应的依据。使用“正方一辩、风险审查员”等明确名称。
角色 Prompt规定身份、立场、职责和互动规则。留空仍可回答，但容易失去立场、变成泛泛而谈。
模型 / 提供商每个角色可以使用不同模型。强模型做裁判，快速模型做普通辩手。
温度越低越稳定，越高越发散。裁判 0.2～0.4；分析 0.5～0.7；辩手或创意角色 0.7～0.9。
发言开关关闭后不进入队列、不响应点名，也不参与裁判选择。用它手动控制辩论阶段，不会删除角色。
↑ / ↓调整角色和用户的发言顺序。主持或裁判通常放在一轮的最后。
展开 / 收起显示或隐藏角色详细设置。角色很多时收起已配置角色。
锁定防止误改名称、Prompt、模型和温度。锁定后仍可使用发言开关。
移除从房间移除角色，旧消息仍保留。只是暂时不让其发言时请用开关。

房间设置与“留空”的作用

房间名称

用于历史记录识别。建议按任务命名，例如“自由意志辩论”“产品风险评审”。

讨论目标

这是所有角色持续遵守的长期任务，不只是最近一句消息。复杂讨论应写清问题、结果、边界、互动方式和停止条件。

讨论目标留空：系统会自动把第一条用户消息作为目标。适合快速聊天，但复杂任务最好单独填写。

可以把“讨论目标”理解为这场讨论为什么存在，把“最近消息”理解为当前需要处理什么。

其他空值

  • 角色 Prompt 为空：角色缺乏稳定职责，不建议用于多人讨论。
  • 消息输入为空：不会发送；如果已经设置讨论目标，可以直接开始自动讨论。
  • API Key 为空：对应模型无法生成内容；API Key 不会写入导出文件。

协作模式与轮次

自由讨论

角色从各自视角自然发言。适合哲学沙龙、多专家观察和开放探索。

方案共创

所有角色追求同一个结果，但分工不同。适合产品、计划、写作和技术评审。

正反辩论

角色需要质疑、回应和反驳对方。建议配置正方、反方和裁判。

固定 N 轮

按角色顺序运行指定轮数，容易控制成本。第一次建议 2～3 轮。

AI 自主判断

由 AI 根据讨论进展决定是否继续。请在目标中写清停止条件。

无限（手动停止）

持续运行直到点击停止，适合开放探索，但需要注意 API 消耗。

发送消息后 AI 自动讨论：开启时，发送消息立即启动角色队列；关闭时，可以先连续输入背景资料，再手动开始。

聊天区按钮

  • 发送：把输入内容加入当前房间；开启自动讨论时会触发 AI。
  • 开始自动讨论：让所有“发言开”的 AI 按当前顺序开始。
  • 插入发言：当前 AI 完成后暂停，把下一次发言机会交给你。
  • 停止：停止自动讨论，已经生成的内容和房间状态会保留。
  • 清空：清除当前聊天记录，角色和设置不变。重要内容建议先整体导出。

用户是否下场，由你决定

纯旁观

不添加用户角色，直接让 AI 自己讨论。

临时插话

点击“插入发言”，在当前 AI 发言结束后接管。

固定参赛

添加用户并调整顺序，轮到你时讨论会等待输入。

挑战裁判

关闭所有辩手，只留下裁判，直接质疑它的结论和判定标准。

如果在 AI 正在输出时关闭其发言，本次内容会完成，从下一次轮到它时开始跳过。

历史、模板与备份

  • 历史房间：点击切换；铅笔用于改名；删除按钮移除房间。
  • 新建房间：创建独立空间，不影响已有记录。
  • 模板导出：保存角色、设置、顺序和发言状态，不含聊天记录和 API Key。
  • 整体导出：额外包含完整聊天记录，仍不包含 API Key。
  • 导入：自动识别模板和整体备份，并保存为独立房间。

角色 Prompt 怎么写

比起长篇人物传记，更重要的是写清楚角色在讨论中必须完成什么。

你是【角色名称】，负责【主要职责】。 你的核心立场或观察角度是【立场】。 你需要重点分析【关键问题】。 每次发言必须回应上一位角色最重要的观点，避免重复。 可以承认对方合理的部分，但必须说明适用边界。 当讨论没有新增信息时进行总结，不要为了延长讨论重复发言。

推荐结构：身份 → 立场 → 职责 → 分析方法 → 互动规则 → 停止条件。

推荐玩法

经典三人辩论

正方、反方、低温度裁判。最稳定，也最适合新手。

4 正 4 反大型辩论

一辩立论、二辩举证、三辩反驳、四辩总结，再由裁判判定。

专家会诊

理论专家、实践专家、数据分析、风险审查和综合决策者共同给方案。

创作工作室

世界观、人物、剧情、逻辑审查、读者观察和主编分阶段协作。

反向压力测试

提案者面对怀疑者、成本控制、安全审查和普通用户，提前暴露问题。

关系观察室

双方视角、情绪观察、逻辑分析和中立调解者区分表达、需求与误解。

大型辩论的阶段控制

  1. 立论：只开启双方一辩。
  2. 质询：开启二辩和三辩。
  3. 总结：只开启双方四辩。
  4. 判定：关闭全部辩手，只开启裁判。

角色越多、轮次越多，API 请求越多。大型房间建议先运行一轮检查角色表现。

避免“公说公有理，婆说婆有理”

把下面的规则写进讨论目标或裁判 Prompt：

  • 每次发言必须明确回应对方的某个观点，不允许只重复立场。
  • 必须承认对方至少一个合理部分，并说明其适用边界。
  • 主张尽量给出案例、证据或可检验条件。
  • 无法回应核心质疑时应明确承认。
  • 裁判必须给出判定标准，不能用“双方都有道理”代替结论。
  • 价值前提不同和逻辑论证失败必须分开说明。
  • 没有新增信息时结束，而不是继续重复。
最后原则：角色数量不是重点。好的房间应该让你知道为什么需要每个角色、谁质疑谁、谁形成结论、用户何时介入，以及讨论什么时候结束。

# 数量、迭代与模型网页发现（V0.6）

在对话区展开“采集数量与扩展检索”。默认目标 60 项，最大保留 200 项，最多 5 轮、50 次采集请求、5 分钟。目标按去重后的资料计数，文件是否能下载单独记录。每页最多 20 项，最后一页可能略超目标，但不会超过本次最大保留数量。当前浏览器清单上限为 200 项，更大的采集任务尚需 IndexedDB 与后台任务支持。

内置来源分别使用 Crossref cursor、Europe PMC cursorMark、DataCite page[number] 和 Internet Archive page；每个来源保存独立游标和命中总数。声明式来源只有查询模板带 `{page}` 才继续分页。失败不推进游标；连续失败暂停该来源本轮尝试，手动继续可以重试。重复结果按 DOI 或规范化网址合并；网址保留功能性查询参数，仅移除常见跟踪参数。已收藏、备注、总结和验证地址保留。

达到目标、请求上限、时间上限、迭代轮次、来源耗尽或连续两轮没有新增资料时停止。提高目标与最大数量后点击“继续采集当前主题”；刷新或项目切换后也能从已保存游标继续。被最大数量截断的本页资料保存在缓冲区，继续采集不会跳过它们。浏览器关闭后任务不会继续运行。

勾选“模型辅助寻找网页”后，使用当前模型整理关键词、最多 3 个扩展检索词和 8 个候选公开网址。候选不是已发现事实：同域服务必须实际访问后，才能使用页面的真实标题、描述和附件链接加入清单。每个种子页最多跟进一层同站链接，限制队列规模；不执行网页脚本、不自动登录、不跨站无限遍历。访问成功不等于主题相关性已确认。启用模型后，来源结果不会直接进入可见清单；系统会将候选分批交给模型，依据用户需求、标题、摘要、作者、资料类型、来源、格式和网址进行全量审核与排序。明确无关、类型明显错误或垃圾占位内容默认隐藏；信息不足、模型漏答或审核请求失败的条目继续保留，避免误删。

页面显示智能审核过滤数量，并提供“查看被智能审核过滤的内容”。过滤条目、审核理由和分数会随项目及历史记录保存。当前图片审核使用来源提供的文字元数据，尚未把图片像素发送给视觉模型。

所有网页请求复用公网 HTTPS 校验、DNS 地址检查、固定连接 IP、每次跳转复核、响应大小及超时限制。外部网页内容和模型生成配置不能作为可执行指令；模型密钥不会发送到候选网站。模型猜错、403 或无法访问的网址记录失败，不当作成功结果。

勾选“检索后自动二次查找文件”，将在保留清单上验证已有文件或发现替代文件，记录真实格式、地址和失败原因。自动查找不会自动下载全部文件；点击单项下载或选择 ZIP 才保存文件。模型网页发现与自动二次文件查找都需要采集服务，静态 GitHub Pages 无法独立执行。

“采集请求”计数为服务任务数：来源分页、页面访问、二次文件查找各算一次；一次文件查找可能包含多个受限的上游请求。所有任务都有独立服务端时间、大小与跳转上限。模型规划与审核不计入该请求数，按模型服务实际用量计费。审核每批最多 25 项，资料越多，模型请求与费用越高。

## 长期部署到 Render

仓库包含 render.yaml，创建一个免费 Node.js Web Service，页面和 API 使用同一域名。构建 npm ci --omit=dev，启动 npm start，健康检查 /api/research/health。服务自动使用 Render 提供的 RENDER_EXTERNAL_URL 校验同域请求，无需手填域名；绑定自定义域名后设置 SITE_ORIGIN 为该域名。

[创建 Render 部署](https://render.com/deploy?repo=https://github.com/z1641818653-blip/AI-Dreamscape)。首次需要登录 Render 并在其界面确认 Blueprint。此步骤未完成前不能认为 Render 服务已经上线。免费实例空闲 15 分钟后会休眠，首次打开可能需要等待启动；见 [官方免费服务说明](https://render.com/docs/free)。自动发布等待仓库检查通过；见 [Blueprint 配置](https://render.com/docs/blueprint-spec)。

## 已验证与边界

自动测试覆盖游标参数、去重、数量上限、请求上限、取消、不跳页、失败重试、模型候选实际访问、文件验证、刷新继续与窄屏。真实 Europe PMC 测试从第一页迭代至 50 项，刷新后继续至 70 项；真实 Zenodo 开发者页面已访问，真实全文自动二次查找并下载成功。当前本机页面模型 API 未配置，模型生成候选链路使用固定响应验收，尚未声称真实模型服务实测通过。Europe PMC 网站文档页本次返回 403，作为访问限制记录；API 检索和全文服务可用。


## 2026-10-23：检索质量改进（预览）

- 开启模型时，目标数量按审核通过项计算，拒绝项会释放候选位置，继续在请求、轮次、时间预算内补搜。被过滤项最多保留 200 项供查看；当前清单仍最多保存 200 项，不保证一定达到目标。
- 所有模型检索都可生成最多四组原语言、英文与专业同义词，不再依赖“模型辅助寻找网页”开关。预算允许时至少尝试两组查询，再决定完成；每组查询的来源游标独立保存，刷新和继续采集不重新翻第一页。
- Crossref、Europe PMC、DataCite 之外新增 Semantic Scholar 论文来源；Wikimedia Commons 从文件命名空间取得真实图片直链、描述、作者、尺寸和许可。第三方来源可能限流或不可达，失败不会删除其他来源结果。实际部署的 Render 服务已验证 Commons 返回两条真实图片记录；本机 Semantic Scholar 收到 429，因此不能保证该来源实时可用。
- “采集设置 → 来源范围”可选 DeepSeek 网页搜索，默认关闭，复用全局 DeepSeek Key，按官方 Search API 成功请求计费。只向 DeepSeek 认证端点发送该 Key，不发送到第三方来源。该来源不会把 `site_icon` 当图片使用。
- 审核必须匹配原需求中的主题、对象、方法、场景、年份与类型。keep 的分数需至少 60；低分或拒绝默认隐藏，缺失结果和 uncertain 进入“待确认内容”，不算通过，也不混入主结果。
- 对图片增加确定性的 logo / favicon / 商标过滤，用户明确检索标志时允许。其余主题契合度依据文件名和描述由模型判断，尚未逐张进行视觉识别；小图预览供人工复核，许可仍以来源页为准。
- 每轮审核后逐步展示通过项；自动查找文件只处理通过项。并发控制实际作用于来源请求，失败页码不推进，取消与预算仍生效。

验收覆盖：首批全不相关后自动补搜、达到数量仍检查替代关键词、分页位置保存、真实文件而非站点图标、厂商 logo 排除、显式 logo 请求保留、不确定项隔离和取消恢复。

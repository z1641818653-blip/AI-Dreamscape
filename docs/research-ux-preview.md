# 资料检索交互测试版

本分支供页面体验与 API 实测，不自动替换正式站。运行 `npm start` 后打开 `/research.html`；本次本地预览端口 8793。

## 本轮三项修复

1. 方向按对象、方向、时间、语言、关键词和排除项分组展开，全部支持多选；提供已选标签、选项内搜索、自定义词条和多轮 AI 补充。相同标签合并，既有选择不被新建议覆盖。同组取并集，不同组同时满足，排除项优先；多个对象分别查询与说明覆盖。
2. “预算”改为“运行限制与预计费用”：简短 / 标准 / 深入预设与自定义轮次、检索阅读次数、时间上限。达到限制保留结果，不代表账户欠费；预计金额不是硬性封顶。
3. 名称、基础、详细层都固定显示原始来源网址；翻译仅改变内容展示，不改原 URL。

## 同时试验的细节

- 已选条件在主页面显示，可回到方向面板修改；新版本先重审已有资料。
- 基础层显示符合 / 排除 / 待确认原因，评分标注为模型判断。
- 论文增加作者、期刊 / 出版来源、预发布类型与证据取得状态；不通过 DOI 或期刊名称推断同行评审。
- 进度显示当前动作、候选与待确认数量；多个快速检索对象逐一显示执行进度。

## 价格快照与用量

核对日期：2026-10-29；金额单位人民币，每百万 Token。

| 模型 | 输入 | 缓存命中 | 输出 |
|---|---:|---:|---:|
| DeepSeek Flash | 1–2 | 0.02–0.04 | 4–8 |
| GLM 5.3 | 8 | 2 | 28 |
| GLM 5.3 Flash | 0.8 | 0.23 | 2.8 |

来源：[DeepSeek 官方价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)、[智谱官方价格](https://open.bigmodel.cn/pricing)。DeepSeek 使用空闲至高峰区间，不推断法定节假日；智谱使用标准刊例价，不计 Flash 限时优惠。Search / Fetch 独立调用按成功请求 0.005 元 / 次估算。Coding Plan 不按 Token 伪造现金或积分换算。

预估假设每轮输入 2,000–48,000 Token；DeepSeek 输出 300–1,500，GLM 输出 1,000–8,000（包含思考）。上下文很长或推理很多时仍可能超出估算。方向拆解、翻译另按实际调用记录，检索预估不能代替供应商账单。

接口成功响应含 usage 时累计输入、缓存命中、输出 Token；reasoning_tokens 是 completion_tokens 子集，不重复加费。未返回用量时标注金额不完整；取消、网络失败可能有无法确认的消耗。公共来源查询不计模型接口费。项目保存用量，不保存 Key。

## 验证

单元检查覆盖多选组合、价格公式、缓存与思考计量、缺失用量和质量标签。浏览器用虚构 Key / 模拟 API 验证双对象实际请求、分层与翻译链接、条件保留、费用随模型变化、用量刷新保存和窄屏布局。真实 API 的相关性和账单仍需使用个人可用 Key 实测。

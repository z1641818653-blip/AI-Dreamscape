# 灵境开放资料工作台

入口：`research.html`。这是灵境中的独立模块，与工作台、聊天室、文档工具并列。主页显示“新项目”入口。

## 使用

1. 在全局配置保存模型服务、API Key 与模型 ID；资料工作台可切换服务商和已保存的自定义模型。
2. 在采集设置中选择一种或多种资料类型与来源，或直接在对话中说明，例如“具身智能的视频、论文、代码和数据集”。
3. 输入研究主题，模型解析条件后查询兼容来源，并对最多 30 项候选解释相关性。未排序候选保留来源排序。
4. 没有模型配置时，关闭模型开关，输入关键词直接检索。国际来源通常适合英文关键词。
5. 通过类型、关键词、年份与“可下载”缩小范围，打开链路查看实际来源、DOI 和许可信息。
6. 点击“AI 总结”，让当前模型依据已获取的元数据生成大致介绍；元数据不足时会明确说明限制。
7. 点击“下载”保存已知文件；“查找文件”会进行二次发现；浏览器无法直接保存时使用“直接打开”。

## 自定义来源

在“采集设置 → 管理自定义来源”中，可以添加无需登录的公开 JSON 检索接口。查询地址使用 `{query}`、`{year}`、`{page}` 占位符，通过点路径描述结果数组和字段映射。模型配置可根据接口说明生成草案，但草案不会直接执行或保存。

每个配置必须发起一次真实测试请求，并成功解析出预览记录，之后才能保存并参加正式检索。当前仅允许 GET、HTTPS 和公开网络地址；本机、私网、认证参数、密钥和任意脚本均不支持。自定义来源配置保存在 `dreamscape_research_sources_v1`，不包含 API Key，并纳入现有无密钥备份。

模型匹配分数不是概率或置信度；来源排序仅表示某来源返回的顺序，不是跨来源统一语义分数。展示标题、摘要和链接均来自来源接口，模型只能改变已获取资源的分数与解释。

## 下载与运行边界

- Internet Archive 结果可通过公开元数据二次发现与资料类型匹配的文件，优先选择 64 MB 内的兼容文件，再比较原始文件与格式；发现后的地址会写回本机清单。
- 同域采集服务可处理跨域文件保存；直链失效会尝试二次发现。需登录、访问受限、网络超时与未发现文件分别显示，静态部署保留“直接打开”兜底。详见 [启动采集服务](research-service.md)。
- 单文件与 ZIP 合集上限为 64 MB；更大资源可通过来源/文件地址获取。媒体下载与 ZIP 内文件保留实际扩展名。
- 暂停只停止新的来源调度；已经发出的请求可能完成。停止会取消当前模型与来源任务，保留已收到结果。
- 真实接口没有保证一定返回可下载文件，来源检索零结果或独立失败都会如实显示。
- 真实清单存于 `dreamscape_research_v1`，同域可共用模型配置；以前独立原型站的数据不会自动跨域迁移。
- API Key 只在原有全局配置中读取，不写进研究清单、导出 CSV 或来源请求。
- AI 总结只发送当前单条记录已有的元数据给用户选定的模型服务，并将生成结果保存在本机清单；临时 Key 不进入总结内容或备份。切换到另一条资料生成总结会取消上一个请求，原资料可以重试。

## 验证

`npm test` 同时运行全站回归和资料模块集成检查。模型测试使用虚构密钥与模拟响应，不消费真实模型额度。公开来源的真实请求另外实测；真实模型账号权限与具体文件地址仍取决于用户配置和来源。

## 项目和历史

顶部可新建、重命名和切换研究项目。每个项目保存独立清单、来源选择、筛选条件、收藏、备注与 AI 总结；最近 5 次真实检索可以恢复，不会重新请求来源。旧版上次清单会迁入默认项目，仍保留旧存储镜像兼容备份。项目数据通过字段白名单保存，不写入全局模型配置或密钥；写入空间不足会保留原存储并提示导出。

当前最多 20 个项目，每个快照最多 200 项。恢复历史保留已保存的个人备注、收藏和较新的文件获取信息。示例体验不覆盖真实项目。对话中的“只看视频”“只看可下载”“2023年以后”和“清除筛选”优先调整当前清单，不请求模型或来源。

后续范围及验收标准见 [实施计划](research-roadmap.md)。
